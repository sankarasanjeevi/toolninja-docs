A complete reference of CutCap's keyboard shortcuts and mouse gestures.

## Navigation & selection

| Action | Shortcut |
| --- | --- |
| Move selection up / down | **↑ / ↓** |
| Jump Premiere's playhead to a caption | **Single-click** the line |
| Edit the selected line | **Enter** |
| Flag the selected line for review | **F** |

## Editing text

| Action | Shortcut |
| --- | --- |
| Edit a single word | **Double-click** the word |
| Edit the whole line | **Double-click** the empty area of the line |
| Split the line at the caret | **Space** (while editing a word) |
| Split the line between two words | **Click** the **"/"** between words |
| Merge a line with the next | **Click** the trailing **"/"** |
| Commit an edit | **Enter** |
| Cancel an edit | **Esc** |

## Playback

| Action | Shortcut |
| --- | --- |
| Play / stop the timeline | **Spacebar** or the **Play / Stop** button |

## Edit history

| Action | Shortcut |
| --- | --- |
| Undo | **Ctrl+Z** |
| Redo | **Ctrl+Y** |

## Search

| Action | Shortcut |
| --- | --- |
| Open Find & Replace | **Ctrl+F** |
| Step through matches | **Enter** / **Shift+Enter** |
| Toggle case-sensitive | **Aa** |
| Toggle whole-word | **W** |
